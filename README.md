# SkillSwap — Skill Exchange Platform

A React + Vite mini web application where users can discover skills, offer skills, search/filter people, send connection requests, and manage a simple dashboard.

## Features
- Responsive landing page
- Explore and search skills
- Category filters
- Skill connection requests
- Add/offer a new skill
- Dashboard with offered skills and requests
- React component-based structure
- Ready for GitHub

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local Vite URL.

## Tech
React, Vite, CSS, Lucide React
